Features

为开发者打造的桌面工作台

专注于 DeepSeek 开发体验，省去繁琐配置，专注核心工作。

内嵌 dsh

启动时自动拉起 dsh web 子进程，以原生 webview 嵌入其 Web 界面，操作体验与原生应用完全一致。

版本检测与一键升级

启动即自动检测 dsh 最新版，发现新版即提示。升级面板展示应用 / Tauri / dsh 三方版本，一键升级并自动重启。

无边框窗口

macOS 使用原生 hiddenInset 无边框（保留红黄绿按钮，页面延伸至顶部）；Windows / Linux 使用系统标题栏。

三平台自动打包

基于 Tauri 与 GitHub Actions 矩阵构建，一条命令为 macOS、Windows、Linux 并行产出安装包。

Getting Started

快速开始

从仓库拉取源码，十几秒即可在本地运行。

1

环境要求

Node.js ≥ 20、Rust stable、pnpm ≥ 9。

2

安装依赖

一键安装全部依赖，支持缓存。

3

本地运行

启动开发模式，自动拉起 dsh 子进程。

4

打包发布

为当前平台或指定平台打包，产物位于 src-tauri/target/release/bundle/。

⬤⬤⬤ dsh-desktop
# 1. 环境要求
node --version   # ≥ 20
pnpm --version   # ≥ 9

# 2. 安装依赖
pnpm install

# 3. 本地运行
pnpm dev

# 4. 打包
pnpm build          # 当前平台
pnpm build:mac      # macOS arm64
